为什么需要它

你的耳机还剩多少电

蓝牙耳机的电量藏在系统设置的三层菜单里，2.4G 键盘的电量藏在厂商驱动里，鼠标的电量通常根本不存在。第三方工具要么常驻后台扫蓝牙、占着音频通道，要么给你一个看起来很确定的错数字。

01
散落在三个地方

耳机、键盘、手柄各有一套查法，想知道"还能用多久"得开三个窗口。

02
数字是猜的

设备断开了还显示"100%"，因为它读的是上次连接的缓存，而不是现在。

03
代价太大

为了一个百分比装一整套驱动框架，常驻扫描、抢占音频通道、拖慢开机。

可信度

每条读数都有出处，没有一条是猜的

这是 Echo 与「显示一个百分比」的工具真正不同的地方。下面是它读电量的全部路径，代码里能逐条对得上。

设备类型读取方式
蓝牙耳机 / 音箱Windows 蓝牙栈把 HFP 上报写在设备节点的未公开属性 {104EA319-6EE2-4701-BD47-8DDBF425BBE5}, 2，Echo 直接从系统读，不碰音频流
蓝牙是否真的连着查 MMDevices 里同名音频端点的 DeviceState，只有 ACTIVE 才算连着 —— 这就是「耳机在包里却显示满电」的根源
2.4G 主动上报类设备每 2 秒推 03 型号 40|41 充电状态 电量，常驻监听、收到即更新，8 秒无帧判为休眠，但保留「上次 xx%」
2.4G 查询类内置协议表：罗技 HID++ 2.0、ATK / VXE / VGN、VAXEE / ZYGEN、Endgame Gear、Nordic nRF、杰理 TLV
标准 HID 电量描述符里声明了 Battery Strength（Usage Page 0x06 / 0x85）就直接读 Feature Report

不是所有 2.4G 都能读。 百元级键鼠套装的接收器往往既不查询也不上报，把电量留在自家驱动软件里。这种设备 Echo 照常列出、标注「无等待上报」，而不是给你一个好看但错的数字。

给读不到的设备留一扇门

抓 8 秒报文，让 AI 把它接进来

大多数工具到此为止。Echo 在设置里留了「2.4G 探测」：并行打开所有可读的 HID 输入接口，把原始报文按十六进制列出来，自动标出取值落在 1–100、可能随电量漂移的字节。

2.4G 嗅探 · 8.0s · 3 个接口
[0] 1D57:FA65 0x000A:0x0000 in=5 03 99 40 01 56 ×4 ← 电量 第4字节 = 86 03 99 41 03 56 ×2 ← 充电中 [1] 046D:C547 0x0001:0x0002 in=20 11 ff 00 07 00 00 00 00 00 00 … [2] 1D57:FA65 0xFF00:0x0001 in=0 ← 不可读 判定：接口 [0] 为主动上报 建议写入 protocols.json

「复制给 Agent 的说明」会把 docs/AGENT.md 连同现场数据拼成一段文本，粘给任意 AI 就能拿到配置。

1
嗅探

8 秒，抓到所有能读的接口和报文，按出现频次归并。

2
标记候选

取值 1–100、且在多帧间漂移的字节会被标出来，其余直接排除。

3
交给 AI

附上帧格式与判断步骤，AI 告诉你电量在第几字节，或直接给配置。

4
写进 JSON

补一条 protocols.json，重启生效，不用改代码。

// %APPDATA%\Echo\protocols.json
[
  {
    "name": "我的接收器",
    "vid": "1D57",
    "usage_page": "FF00",
    "report_id": "08",
    "payload": [125, 114, 2, 0, 1, 7, 1],
    "level_offset": 7,
    "level_max": 100,
    "mode": "auto"
  }
]

推荐

下载 Echo.exe

单文件、约 12 MB，不需要装 Python，没有安装程序，也没有开机引导。第一次运行会在 %APPDATA%\Echo\ 建三个配置文件。

去 Releases 取最新版 →
从源码

两条命令跑起来

pip install pywebview
python app.py

需要 Windows 10/11 与 WebView2 运行时（Win 11 自带，Win 10 装了 Edge 就有）。

不联网

没有更新检查、没有统计上报、没有远程配置。想验证的话，断网它照样跑。

不写日志

只有 ECHO_DEBUG=1 启动时才会打开调试面板。配置全在本机。

不占通道

空闲时不轮询蓝牙、不碰音频流；只有主动上报类设备挂一个监听线程。

快捷键：Ctrl + R 刷新 · Ctrl + M 收进托盘 · Esc 关闭弹层。关闭窗口默认只是收进托盘，真正退出用托盘右键 → 退出。
